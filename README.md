# Winget Installers

A portable Windows 10/11 setup manager. **Status: design/planning; no implementation committed.**

The app helps prepare, install, and reconfigure Windows PCs using winget, PowerShell, manual checkpoints, and Windows Update. It supports reusable YAML profiles and per-run Install/Skip choices.

See [requirements](docs/PRODUCT_REQUIREMENTS.md), [architecture](docs/ARCHITECTURE.md), [configuration](docs/CONFIGURATION.md), and [roadmap](docs/ROADMAP.md).

No paid code signing is planned. The app is internet-first, may run from USB, and does not manage credentials.
